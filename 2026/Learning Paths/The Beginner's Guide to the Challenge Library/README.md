# Basics and Onboarding

**Flags:** A flag is a string of text that found in a challenge that proves you've completed it. They are submitted on the PicoCTF (CyLab Security Academy) Page.

They look like: **picoCTF{l33tsp34k_phr4s3_1234abcd}**


# Definitions of Categories

**General Skills:** Build the foundational skills essential for  cybersecurity. Focuses on topics like:
      - Linux
      - Base64
      - Navigating File Systems

**Cryptography:** Challenges involving encryption and decryption. Early ones introduce the foundational cryptographic skills such as Base64 while more difficult challenges will have you encrypting and decrypting AES and RSA. Focuses on topics like:
      - Encryption
      - Decryption
      - Hashing

**Forensics:** Investigate file systems and disk images. Can range from digging through a file system to recovering deleted data from a disk. Focuses on:
      - File management
      - Network captures
      - Packet captures

**Web exploitation:** Serves as a good walkthrough and introduction to web-based penetration testing. Find hidden directories left open on websites or misconfigurations that allow for exploitation. Focuses on:
      - Manipulating cookies
      - SQL injection
      - Finding hidden hosts

**Reverse Engineering:** Given a compiled program, what can you do to figure out how it works and force it to give the flag. Usually takes an input in that program that will give the user the desired flag. May be combined with other skills such as **Web Exploitation** or **Cryptography**. Focuses on:
      - Input manipulation
      - Reading compiled programs
      - Programming skills

**Binary Exploitation:** Exploit memory-safety vulnerabilities in precompiled programs. Goes a step above the skills required for **Reverse Engineering**. Focuses on:
      - Memory overflow
      - Formatting string bugs
      - Use-after-free

# Challenges Design and Approach

Challenges are designed to take only a few minutes, though research for them may take far longer. The best approach is to attempt a challenge once, and take what you learn from that and what you couldn't figure out, and research the parts you didn't know before reattempting. Research should only take about 30 minutes, but that doesn't mean it will be straightforward. As you move to the later challenges especially, more than one attempt will be required.
