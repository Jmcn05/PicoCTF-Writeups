# PicoCTF Writeups

A collection of my personal writeups, notes, scripts, and solutions for challenges from **picoCTF / CyLab Security Academy**.

The purpose of this repository is to document my learning process, practice cybersecurity concepts, and provide an educational reference for others working through similar challenges.

## Spoiler Warning

This repository contains **solutions and walkthroughs for CTF challenges**.

If you are currently attempting a challenge yourself, I strongly recommend trying to solve it before reading the corresponding writeup.

Some writeups may include:

- Commands used to solve the challenge
- Exploitation techniques
- Scripts and proof-of-concept code
- Screenshots
- Challenge flags
- Complete solutions

Proceed accordingly.

## Repository Organization

Writeups are organized by **competition/year**, then by **challenge category**, and finally by individual challenge.

Each challenge directory may contain:

- `README.md` — Full challenge writeup
- `solve.py` — Python solution or exploit
- `solve.sh` — Shell-based solution
- `files/` — Supporting files when appropriate
- `images/` — Screenshots used in the writeup

## Challenge Categories

Challenges may include:

- General Skills
- Cryptography
- Forensics
- Reverse Engineering
- Binary Exploitation
- Web Exploitation

## Writeup Format

Most writeups follow a similar structure:

1. **Challenge Information**
2. **Objective**
3. **Initial Analysis**
4. **Enumeration / Investigation**
5. **Solution**
6. **Commands / Code**
7. **Flag**
8. **Key Takeaways**

The goal is not simply to record the answer, but to document **why the solution works** and what can be learned from the challenge.

## Usage

Feel free to use these writeups as a learning resource or reference.

Whenever possible, attempt the challenge yourself before consulting the solution. CTFs are considerably more useful when you spend some time being confused first.

## About picoCTF

picoCTF is a cybersecurity Capture the Flag platform originally developed by Carnegie Mellon University.

The platform and its educational resources now continue through **CyLab Security Academy**.
